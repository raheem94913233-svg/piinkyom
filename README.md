# سيرفر إشعارات واتساب (Render)

سيرفر يرسل رسائل الطلبات للزبائن من رقم الواتساب المربوط في لوحة التحكم.

## خطوات النشر

1. أنشئ مستودع (Repository) جديد على GitHub وارفع فيه ملفات هذا المجلد.
2. ادخل على https://dashboard.render.com › New › Web Service › اختر المستودع.
   - Build Command: `npm install`
   - Start Command: `npm start`
3. من **Environment** أضف:
   - `SERVICE_TOKEN` = كلمة سر تختارها أنت (نفسها ستضعها في لوحة التحكم).
   - `AUTH_DIR` = `/var/data/auth`
4. من **Disks** أضف Disk واجعل **Mount Path = /var/data** (يحتاج خطة مدفوعة Starter).
   بدون Disk تُحذف جلسة واتساب عند كل إعادة تشغيل وتحتاج تمسح QR من جديد.
   (ملف render.yaml موجود ويضبط كل هذا تلقائياً لو استخدمت New › Blueprint.)
5. بعد النشر انسخ رابط السيرفر مثل: `https://xxxx.onrender.com`
6. في لوحة تحكم المتجر › واتساب: أضف اسم السيرفر + الرابط + كلمة السر ثم **حفظ السيرفر** و**تفعيل**.
7. اضغط **اختبار** وسيظهر رمز QR — امسحه من واتساب › الأجهزة المرتبطة › ربط جهاز.

زر **إعادة تهيئة** يعيد الاتصال مع الاحتفاظ بالجلسة. زر **تسجيل خروج وإظهار QR** يحذف الجلسة عمداً ويولّد رمزاً جديداً.

## نقاط النهاية
- `GET /status` — حالة الاتصال + رمز QR (يتطلب Authorization: Bearer TOKEN)
- `POST /send` — `{ "to": "96894913233", "message": "..." }`
- `POST /restart` — إعادة تهيئة الاتصال مع الاحتفاظ بالجلسة
- `POST /logout` — تسجيل خروج وحذف الجلسة وتوليد QR جديد
